# Stubborn defense

I started working on this game as a side project. The whole game design is an answer to the question: how can I turn chess into a tower defense game?

I treat it as a prototype and as a game design learning project. My only ambitions for this game is to get it to a somewhat playable/fun experience. Once the current TODOs are done I will publish it on itch.io or similar platform as a 0.1.0 version. That said, anyone is free to download and execute the game in its current state.
